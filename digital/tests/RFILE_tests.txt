Register file (RFILE.dig): B-F (two 74173 each), X and Y (two 74191 each, a 16-bit counter).
  - REG_LD_EN loads the register in B_10_8 (Rdst). B-F load on the rising clock edge. X and Y
    have the 74191's asynchronous load, ORed with CLK, so they load while CLK is low.
    Register 0 is A, which is in the ALU: it only pulls A_LD low.
  - REG_OE_EN puts the register in B_7_5 (Rsrc) on DB_OUT, or the one in B_10_8 with SRC_SEL = 1.
    For register 0 it only pulls A_OE low.
  - With nXY_INC = 0 the XY pair counts on the rising clock edge (up if XY_DIR = 0, down if 1),
    and nXY_AOE puts it on the address bus (AB_OUT).
  - RST clears B-F (X and Y have no reset).
DB_IN only changes while no load is on (see MAR_tests.txt).
