Memory address register (MAR.dig): four 74191 up/down counters.
  - nMARL_LD / nMARH_LD load D_IN into the low / high byte. The 74191 load is asynchronous,
    so it's ORed with CLK: it loads while CLK is low (the second half of a cycle), and the
    MAR follows D_IN for as long as the load is on.
  - With nMAR_INC = 0 it counts on the rising clock edge, up if MAR_DIR = 0, down if 1.
  - nMAR_OE puts it on the address bus (A_OUT).
D_IN only changes while no load is on, like in the CPU: there the load turns off with the
clock edge, before the data bus changes. In a test row everything changes at once, so a new
D_IN together with the end of a load would race.

## load each byte
D_IN nMARL_LD nMARH_LD nMAR_OE nMAR_INC MAR_DIR CLK A_OUT
# (the active-low inputs start at 1, so no load is on yet)
0x00 1        1        0       1        0       0   X
0x34 1        1        0       1        0       0   X
0x34 0        1        0       1        0       0   X
0x34 1        1        0       1        0       0   X
0x12 1        1        0       1        0       0   X
0x12 1        0        0       1        0       0   0x1234
0x12 1        1        0       1        0       0   0x1234
# no load: a new D_IN doesn't matter, and neither does the clock
0x99 1        1        0       1        0       0   0x1234
0x99 1        1        0       1        0       C   0x1234
# the load is transparent while it's on
0x99 0        1        0       1        0       0   0x1299
0x99 1        1        0       1        0       0   0x1299
# both bytes at once
0x56 1        1        0       1        0       0   0x1299
0x56 0        0        0       1        0       0   0x5656
0x56 1        1        0       1        0       0   0x5656
# output enable
0x56 1        1        1       1        0       0   Z
