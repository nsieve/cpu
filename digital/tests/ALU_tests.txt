ALU (ALU.dig): the accumulator (two 74173), its input mux (two 74257), the ALU (two 74382)
and the shifter.
  - A loads on the rising clock edge when A_LD = 0 (active low, it comes from the register
    file's decoder) or nA_LD = 0 (the ALU operations, straight from the control unit): from
    D_IN if A_SEL = 0, from the ALU if A_SEL = 1. RST clears it.
  - D_OUT is the only output to the data bus, with two 74245 on it: A_OE = 0 (active low)
    puts A there, and nSHR_OE = 0 the shifter (A shifted right, bit 7 = SHR_IN0). Only one of
    them at a time.
  - The ALU works on A and D_IN with ALU_S0-S2 and ALU_CIN. Z, C, N and V are always out:
      S = 0 clear, 1 D_IN - A, 2 A - D_IN, 3 A + D_IN, 4 XOR, 5 OR, 6 AND, 7 0xFF
    The subtractions are A + NOT(B) + carry in, so C = 1 means no borrow.
    C and V go through a 74157: while nSHR_OE = 0 they're A[0] (the bit shifted out) and 0.
    The ALU result only goes into A (through the 74257), so every case checks the flags first,
    then loads the result into A and reads A on D_OUT.
A_LD and A_OE are active low but their names don't start with n, so they get a default here:
defaults: A_LD=1 A_OE=1
