MAX7219 model (max7219_sim.dig): a 16-bit shift register clocked by SCLK (MOSI goes in at
bit 0, so the frame is sent MSB first), and on the rising edge of CS the register in bits
11-8 (1-8 are the digits DIG1-DIG8) loads bits 3-0.

## one digit
SCLK MOSI CS DIG1 DIG2 DIG3 DIG4 DIG5 DIG6 DIG7 DIG8
# frame 0x0305: digit 3 = 5
loop(i, 16)
C    ((0x0305>>(15-i))&1) 0 X X X X X X X X
end loop
0    0    C  0    0    5    0    0    0    0    0

## all 8 digits
SCLK MOSI CS DIG1 DIG2 DIG3 DIG4 DIG5 DIG6 DIG7 DIG8
loop(d, 8)
loop(i, 16)
C    (((((d+1)<<8)|(8-d))>>(15-i))&1) 0 X X X X X X X X
end loop
0    0    C  X    X    X    X    X    X    X    X
end loop
0    0    0  8    7    6    5    4    3    2    1
# the other registers (decode mode, intensity...) don't change the digits
loop(i, 16)
C    ((0x0A08>>(15-i))&1) 0 X X X X X X X X
end loop
0    0    C  8    7    6    5    4    3    2    1
# without the CS edge nothing changes
loop(i, 16)
C    ((0x010F>>(15-i))&1) 0 X X X X X X X X
end loop
0    0    0  8    7    6    5    4    3    2    1
