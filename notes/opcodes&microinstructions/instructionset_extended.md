# Instruction Set (Extended)

Generated by `programs/gen_docs.py`.

These are the control bits each instruction activates in every microstep. A bit in the list means the signal is active, so for an active-low bit (`n...`) it means the EPROM outputs a 0. The names and bits are in `controlbits.md`, and the summary of every instruction is in `isa.md`.

Step 0 is the fetch, and it's the same in every instruction. When a step depends on the flags, the bits are split by condition, for example `if C:`. Instructions without a subOp use bits `[10:8]` as a register, so their microcode is the same for all 8 values.
